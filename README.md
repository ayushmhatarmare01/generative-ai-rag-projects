# Generative AI and RAG Projects

Practical implementations of Retrieval-Augmented Generation (RAG) systems using Python, embeddings, vector databases, and Large Language Models (LLMs).

## About This Repository

This repository explores how to build AI applications that retrieve relevant information from external documents and use it to generate context-aware answers.

It focuses on the complete RAG pipeline, from document ingestion and processing to retrieval, answer generation, evaluation, and responsible deployment.

## Topics Covered

- RAG Fundamentals and Architecture
- Document Loading and Text Extraction
- Text Cleaning and Chunking
- Embeddings and Semantic Search
- Vector Databases
- Information Retrieval and Reranking
- Prompt Construction and Context Management
- Grounded Question Answering
- Source Citations
- RAG Evaluation and Optimization
- Advanced RAG Techniques
- Reliability and Safety

## Learning Objectives

1. Understand the architecture and purpose of RAG.
2. Process documents into useful text chunks.
3. Generate embeddings and retrieve relevant information.
4. Connect retrieval systems with LLMs.
5. Build answers grounded in source documents.
6. Evaluate retrieval quality, answer relevance, and factual grounding.
7. Develop practical RAG applications with clear documentation.

## Project Standards

Each completed project will aim to include architecture documentation, setup instructions, example documents, test questions, evaluation results, and known limitations.
